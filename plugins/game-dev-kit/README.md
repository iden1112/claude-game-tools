# game-dev-kit

The 20 game plugins from claude-code-game-development (MIT), merged into one plugin. Each specialty has a skill (patterns and gotchas), an agent, and a slash command:

godot-development, unity-development, unreal-engine, game-architecture, input-systems, save-systems, localization, shader-programming, animation-systems, audio-systems, ui-game-design, ai-game-behavior, physics-simulation, procedural-generation, level-design, playtesting, performance-optimization, asset-pipelines, multiplayer-networking, monetization-ethics.

Left out on purpose: the optional `libre-gamedev-hooks` plugin (runs scripts automatically on every tool use) and the 65 non-game plugins in the same repository.
