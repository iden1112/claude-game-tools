# game-polish

| 스킬 | 하는 일 | 출처 |
|---|---|---|
| game-assets-enhancement | 게임 그래픽 업그레이드: 스타일 가이드, 스프라이트 하나씩 생성(fal.ai), 여러 겹 패럴랙스 배경, 손맛 연출 | claude-skill-game-assets-enhancer (Adam Lyttle, MIT) |
| car-engine-sound | 자동차·오토바이·배 엔진 소리 (RPM 따라 음높이가 변해요). 파일 없이 합성 또는 녹음 반복 | CarEngines (buntine, CC0) + car-engine.js |

game-assets-enhancement 의 이미지 생성은 fal.ai 연결(본인 계정)이 필요해요. 연결이 없으면 스타일 가이드·배경 겹 구조·연출은 그대로 하고, 그림은 코드로 그리거나 다른 AI로 만든 이미지를 받아서 써요.
