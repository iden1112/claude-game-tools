# threejs-game-tools

Tools for 3D web games made with Three.js (r128 or newer), as single HTML files.

- **three-fx**: `fx3d.js` v2, an effect library in a crisp hand-made style (toon, pixel or soft look): water splashes and ripples, sparkles, bronze/silver/gold/rainbow reveals, coins, confetti, level-up, hit sparks, explosions, poof, dust, debris, leaves, fire, smoke, bubbles, auras, trails, floating text, and pixelfx effects on sprites in 3D.
- **three-models**: `character3d.js`, cute detailed characters and 8 NPC presets (faces, hairstyles, hats, outfits, walk/run/wave/cast/cheer/nod, blinking and breathing), and `models3d.js`, models built in code: fish (5 shapes), trees (4 kinds), rocks, islands with ground height, waves, grass, boats, houses, crates, lanterns.
- **three-game-dev**: how to build and test Three.js games here: r128 traps, structure, performance, `three-stub.js` to test without a GPU or internet, `render-check.py` and `lab-template.html` to screenshot real frames, and `demo-template.html`.

Works with the pixel-art-tools plugin (pixelfx) for pixel effects in 3D. MIT.
