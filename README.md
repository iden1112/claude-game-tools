# iden1112 게임 PC 🖥️

내가 만든 웹 게임 모음이에요. 사이트를 열면 **윈도우 바탕화면**처럼 보이고, 폴더를 두 번 클릭하면 게임이 나와요.

**▶ 열기: https://iden1112.github.io/claude-game-tools/**

```
games/
├── shooting/   슈팅·액션     훈련장 1v1 · 하늘 전선
├── racing/     레이싱·비행   무한 드라이브 · 스카이 링 러시
├── fishing/    낚시          픽셀 피싱 빌리지(최신·이전) · 바다낚시 · 낚싯배 강화 단계
├── healing/    힐링·키우기   고래 등 농장 · 작은 행성 정원
├── minigame/   미니게임      숨 참기 다이버 · 잿불 대장장이
└── tools/      도구·미리보기 비행기 모델 미리보기 · 3D 게임 도구 미리보기
source/training-1v1/          훈련장 1v1 원본 코드 (src/*.js 를 build.py 로 합쳐요)
```

- 게임 하나만 바로 열기: `https://iden1112.github.io/claude-game-tools/games/<분류>/<게임>/`
  예) 훈련장 1v1 → https://iden1112.github.io/claude-game-tools/games/shooting/training-1v1/
- 이 브랜치(`gh-pages`)는 웹사이트용이에요. Claude 플러그인 모음은 `main` 브랜치에 있어요.
